# Data-center counteroffer salience

This family is a paired, land-only mechanism diagnostic derived from the
schema-aligned counteroffer-adoption case. Both conditions expose the same
valid starter offer and the same complete written counteroffer. The treatment
condition additionally summarizes field-level differences computed solely from
those two public packages.

The experiment asks whether redundant delta annotation improves exact adoption
of the written counteroffer. It does not reveal private policy, change the
binding terms, or assign partial negotiations any project cash-flow meaning.
Both cases share one curated project and therefore support only a within-project
salience diagnosis, not population generalization or a model ranking.
