# Data-center counteroffer acceptance affordance

This family is a paired, land-only mechanism diagnostic. Both conditions begin
with the same starter package and receive the same formal public counteroffer.
The action schema is shared. After the counteroffer, one protocol requires the
developer to re-emit the complete package; the other permits acceptance by the
counteroffer's public offer ID.

The verifier still requires an exact executed package and valid signature. The
comparison isolates structured-package re-emission burden from commercial
agreement grounding. Both cases share one curated project and support no
population, causal, or model-winner claim.
