# Public integrated data-center project cases v1

This pack adds three report-only, tier-three cases from independent SEC filing
clusters. Each case combines multiple commercial layers whose timing affects
future cash flow rather than testing one agreement in isolation:

- Polaris Forge 1: contracted capacity, phased operating status, secured debt,
  delivery risk, and project-specific land/power evidence;
- Black Pearl: land and interconnection, phased rack-ready rent, construction
  financing, restricted proceeds, and conditional cost-overrun reimbursement;
- Horizon: customer acceptance, service tranches, delayed-draw financing,
  escrow release, remarketing support, and a separate performance guarantee.

The agent sees compact paraphrases and opaque evidence identifiers. The
evaluator retains the SEC accession, document, clause locator, hidden oracle,
and failure mechanisms. Source documents are public but are not vendored, and
no upstream byte hash is claimed because the cases were authored from reviewed
web representations rather than a preserved byte-for-byte filing download.

Together with the prior integrated Denton case, the family now has four
independent integrated project clusters. This remains an exploratory diagnostic,
not enough for population generalization or inferential model ranking.
