# Public-source data-center agreement cases v1

This pack contains five report-only cases derived from five distinct SEC filing
clusters. The agent sees compact paraphrases with opaque evidence identifiers;
the evaluator retains the source accession, document, clause locator, oracle,
and failure mechanism.

The cases cover conditional ground-lease commencement, phased colocation
delivery, large-load electric-service gates, unavailable credit facilities,
and linked land/power/construction terms. The original filing documents are not
vendored. `source_catalog.json` provides stable SEC URLs and locators. Direct
byte retrieval from the shell was denied by SEC with HTTP 403 on 2026-09-03,
so no upstream byte hash is claimed.

Five public filing clusters support exploratory cross-project diagnostics, not
population generalization, causal effects, or a model-winner claim.
