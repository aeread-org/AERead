# Indicator-map public integrated data-center expansion cases v2

This pack derives from `public_integrated_expansion_v1`. It preserves the three
new SEC-grounded project observations, issuer-project clusters, authority,
world seeds, state vocabulary, and hidden oracle leaves. The only change is a
final prompt instruction encoding candidate actions, claims, and evidence IDs
as complete boolean maps and the external-action signal as one boolean.

The matching campaign must enable the indicator-map schema and normalize true
entries back to the family’s canonical arrays before deterministic scoring.
The pack is exploratory and does not support population generalization or an
inferential model ranking.
