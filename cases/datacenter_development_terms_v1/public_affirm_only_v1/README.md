# Public five-cluster affirm-only replication v1

This derived pack applies one frozen sentence to each case in `public_v1`: the
`actions` and `claims` arrays should include only labels the analyst affirms as
supported, while rejected candidates should be omitted.

The derived cases use the neutral visible split identifier `public_v1b`. Each
variant preserves its baseline title, evidence, hidden oracle, authority, cutoff,
source cluster, and world seed. The pack manifest is bound to the exact base-pack
digest, so any upstream case change requires a new derived-pack identity.

The five SEC filing clusters are exploratory independent-source replication for
the candidate-selection intervention. They do not support a population causal
effect, inferential model ranking, or model-winner claim.
