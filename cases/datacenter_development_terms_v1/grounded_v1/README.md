# Grounded data-center commercial-state cases

This pack contains four data-center and compute-infrastructure cases derived
from a user-provided, sanitized calibration pack. The upstream pack states that
its commercial relationships were verified before sanitization; original
records, identifiers, dates, entities, and amounts are not included here.

The cases exercise quote normalization, execution cutoffs, site/power
reconciliation, and formula-driven cash-flow readiness. They share overlapping
source lineage and therefore form one conservative archive cluster. Case count
must not be interpreted as independent-project sample size.

The agent sees only the public case and candidate response vocabulary. Gold
states, arithmetic checks, required claims/actions, and source roles remain
evaluator-only. Every case is report-only and forbids external actions.
