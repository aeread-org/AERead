# Public integrated data-center expansion cases v1

This pack adds three public-primary-source project clusters to the data-center
agreement-terms family:

- Galaxy Helios: phased lease delivery, approved versus contracted power,
  deferred billings, loan draws, and stabilization-triggered covenants.
- TeraWulf Lake Mariner: executed versus commenced customer leases, prepaid
  rent, leasehold land, improvement reversion, and conditional capacity.
- Bitdeer Tydal: an executed open-book cost-plus design-build agreement with
  joint governance, cost reapproval, audit, equipment-risk, schedule, and
  suspension terms.

The observations paraphrase primary SEC filings and a filed material contract.
Original filing artifacts are not vendored. The source catalog pins accession,
document, URL, and clause-level locators; hidden oracles retain the source
references and failure mechanisms. Cases are report-only and use opaque
evidence IDs.

The independent sampling unit is the issuer-project filing cluster. Three cases
are useful for mechanism coverage and descriptive model diagnostics, not
population inference or a general model ranking.
