# Public integrated-underwriting mechanism pack v1

This diagnostic pack decomposes the linked Denton land, power, and construction
case into three clause mechanisms: assignment effectiveness, coterminous
land-power termination, and change-order-adjustable GMP construction pricing.

Each mechanism has two paired cases. The baseline case uses ordinary assessment
wording. The affirm-only case adds one sentence telling the analyst that the
`actions` and `claims` arrays should contain only labels it affirms as supported,
with rejected candidates omitted. Within a pair, title, evidence, hidden oracle,
authority, cutoff, and world seed are identical.

All six cases derive from one public SEC filing cluster. The pack diagnoses
composite-load and response-semantics mechanisms; it does not add independent
projects or support a population, causal, model-ranking, or winner claim.
