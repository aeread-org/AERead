# govsim cases

[`v1/`](v1/) is the AERead-generated 9-cell corpus (3 scenarios --
`fishing`/`sheep`/`pollution` -- x 3 scripted policies --
`sustainable_v1`/`greedy_v1`/`mixed_v1`) wrapping the pinned upstream
[`giorgiopiatti/govsim`](https://github.com/giorgiopiatti/govsim) checkout
(commit `1d11adf047b24fa2ba0d44a1d4931015ea2e5210`). It contains 9 case
files, `pins.json`, and `corpus_manifest.json`.

Unlike `tau3_retail`, there is no discrete upstream task list to import --
upstream ships Hydra experiment YAML configs, not per-task JSON records
(see `docs/govsim_adapter_spec.md` section 1). Every case here is
procedurally generated by `src/aeread_families/govsim/cases.py`; its default
output directory is this `v1/` directory. `pins.json` records the exact
upstream source files this adapter executes (never a per-task hash, since
there is no per-task file), so regenerated output must be reviewed as a
content change rather than a folder-only change.

The measurement leaves (`govsim_no_collapse`, `govsim_threshold_adherence`,
`govsim_survival_months`, `govsim_total_harvest`, `govsim_equality_gini`) are
a later milestone; this corpus and the kernel family plugin
(`src/aeread_families/govsim/environment.py`) land first.
