# Exchange v1 cases

- [`v0/`](v0/) is the official public scored set. It contains four case JSON
  files. Its [`diagnostics/`](v0/diagnostics/) directory holds panel-analysis
  artifacts that are not scored cases.
- [`specialized/`](specialized/) contains bundle-under-budget and procurement
  worlds with dedicated oracles. They are useful for development but are not
  yet wired as an official scored family.

Experiment ladders, mechanisms, and treatment variants remain under
`configs/exchange_economy/` because they configure experiments rather than
identify a stable public case set.
