# Data-center counteroffer action schema

This paired, land-only diagnostic holds the formal public counteroffer, prompt,
profile, and available schema catalog fixed. In one condition the developer
must choose acceptance from the shared multi-action offer schema. In the other,
the post-counter phase selects a dedicated acceptance-only schema.

Both paths still require the correct public counteroffer ID, exact executed
terms, and a valid signature. The comparison tests state-specific action-schema
steering on one curated project; it supports no population, causal, or
model-winner claim.
