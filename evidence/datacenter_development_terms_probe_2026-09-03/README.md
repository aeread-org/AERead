# Data-center development terms probe — 2026-09-03

This directory is the sanitized, PR-ready projection of a two-cell OpenRouter
probe on the corrected synthetic `full-stack-cutoff-001` case. Complete provider
payloads, prompts, event stores, and evaluation receipts remain under the ignored
local `runs/datacenter_development_terms_v1_probe/` directory.

The preflight probe exposed an oracle ambiguity: an elective land-option
extension had been counted as binding cash. The case was corrected to state that
the developer had delivered an irrevocable written extension election. Both
initial model results were invalidated, and both models received one fresh
attempt on the corrected case.

GLM completed and produced a replay-verified score. Mistral's fresh attempt
failed the structured-output provider contract and is retained as an excluded,
typed missing measurement—not converted to a zero and not selectively retried.
This is one synthetic project cluster, so the evidence supports integration and
case-difficulty diagnostics only. It does not support a model ranking or a
general claim about real data-center projects.
