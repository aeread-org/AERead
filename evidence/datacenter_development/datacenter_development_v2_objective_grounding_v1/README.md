# Data-center V2 objective-grounding campaign

This directory is a sanitized, PR-ready projection of a six-cell OpenRouter
campaign on one bounded V2 data-center agreement-stack case. Three inference
seeds are paired across two open-source routes. Only the developer is live;
five deterministic counterparties counter with one complete calibrated package.

The authoritative prompts, provider payloads, event stores, and complete
evaluation receipts remain under the ignored local
`runs/datacenter_development_v2_objective_grounding_v1/` directory. Receipt and
event digests bind this publication to that local evidence. Free-form
negotiation messages are deliberately omitted.

The primary leaf is safe developer-objective attainment. It grants credit only
to a completed, binding, constraint-satisfying, temporally valid stack at or
below the certified developer-NPV optimum. Raw developer NPV, completion,
contract integrity, constraints, temporal compliance, intentional resolution,
and reference dominance remain separate facts.

Operational failures remain typed exclusions rather than score zero. Valid
model-produced invalid actions, rejections, walks, and exhausted negotiations
remain included outcomes. Because all cells use one curated project cluster,
the campaign supports objective-grounding diagnosis only—not population
generalization, a model winner, or a causal model effect.

For excluded cells, `observed_usage` counts only successful provider calls
already sealed before the terminal failure. It is therefore a spend lower bound,
not a claim that the provider billed nothing for the failed call itself.
