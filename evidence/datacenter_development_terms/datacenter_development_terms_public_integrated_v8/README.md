# Provider-paced public integrated campaign v8

This sanitized, PR-ready projection runs three independent SEC-grounded
data-center project clusters with one fresh predeclared seed and two pinned
Apache-2.0 open-weight routes. DeepInfra calls ran in a deterministic queue with
a 30-second cooldown after each attempt, while the Google queue ran concurrently.
The frozen full panel used no retries, cache, or provider fallback.

All six cells completed, were included, route-verified, and replayed. Every hard
gate passed. DeepInfra completed 3/3 cells under pacing, compared with 1/3 in the
unpaced V7 panel; this is evidence that pacing is operationally promising, not a
causal estimate because seed and execution time also changed. Exact campaign
cost was $0.00385881705.

Qwen scored 1.0 on all three projects. Mistral scored 1.0 on Helios and Tydal
and 0.9444 on Lake Mariner. The raw Lake delta is not interpretable: the schema
did not say whether four dollar figures stated in millions should be returned
in millions or base dollars, and Mistral used millions while the oracle used
base dollars. Mistral also returned 250 rather than the visible 750 MW power
limit; that separate error is unambiguous. Helios and Tydal are the two valid
interpretable pairs and both tied at 1.0. The Tydal correction remained valid:
both routes returned the visible 22nd-day invoice term.

This campaign expands mechanism coverage and supplies descriptive diagnostics.
It does not establish a model winner, inferential ranking, project-population
generalization, or causal effect. Full prompts, provider payloads, model
reasoning, complete receipts, and verbose failure messages remain in ignored
local run state.
