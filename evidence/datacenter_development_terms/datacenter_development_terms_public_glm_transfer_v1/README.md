# Public GLM integrated-case transfer diagnostic v1

This sanitized add-on applies one pinned GLM 5.3 Flash/DeepInfra route to the
integrated Denton land/power/construction baseline. It uses the exact public
case hash, prompt schema, minimal-chat harness, 900-token output limit, timeout,
and inference seeds from the prior candidate-screen campaign. Nine sealed
baseline cells for Mistral, Qwen, and GPT-OSS are hash-bridged rather than rerun.

One of three GLM calls completed; the other two were rate-limited and remain
typed operational exclusions without retry. The completed response passed the
hard gate with score 0.9667, all required actions and claims, and no forbidden
selection. Successful-call cost is a $0.00018159075 lower bound.

Only seed 316001 forms a reportable four-model row: GLM and Mistral passed,
while Qwen and GPT-OSS failed the deterministic hard gate. The predeclared
decision remains `inconclusive_operational_missingness`, because two of three
planned GLM seeds are unavailable. GLM is therefore not yet qualified for the
five-cluster replication under the frozen rule.

This is a single-source model-transfer diagnostic, not an inferential model
comparison. It does not establish a population effect, project generalization,
ranking, or winner. Raw prompts, provider payloads, reasoning, complete
receipts, and failure messages remain in ignored local run state.
