# Grounded data-center commercial-state variance v1

This is the sanitized projection of a 24-cell OpenRouter panel: four
source-grounded, sanitized data-center commercial cases, two exact open-source
model/provider routes, and three paired inference seeds. All 24 cells completed,
were included, and replayed from their sealed receipts. Reported cost was
$0.0030291624.

The cases cover colocation quote normalization, service-order execution cutoffs,
site/power reconciliation, and formula-driven build economics. They share
overlapping source lineage and are therefore one conservative archive cluster.
The panel measures case and response variance; it does not establish independent
project generalization, a population effect, an inferential ranking, or a model
winner.

One included site/power response selected a declared forbidden claim and received
primary score zero from the deterministic hard gate. Its component metrics remain
published for diagnosis. Operational failures would remain excluded rather than
becoming zero; none occurred in this panel.

Raw provider payloads, prompts, reasoning, complete receipts, and failure messages
remain in the ignored local run directory. This publication contains only typed
case identifiers, selected response labels, component metrics, route checks, and
source digests.
