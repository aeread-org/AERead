# govsim first live panel

One unscored route canary plus one case per scenario (fishing, pollution, sheep) on the pinned OpenRouter GLM 5.3 Flash/Parasail route.

Two things a reader needs. The corpus's nine cases are three configurations repeated three times -- identical world seed and env_cfg, differing only in a policy assignment that has no effect when every seat is the model -- so the panel runs three. And this adapter's discuss and reflect actions carry no content, so what is measured is the common-pool dilemma with communication removed.

Comparative leaves are scored against govsim_sustainable_v1, produced by running that scripted policy through this same environment provider-free; the policy digest and the three values are in the plan.
