# econevals first live panel

One unscored route canary plus a frozen six-case panel, two cases from each of the three econevals tracks, on the pinned OpenRouter GLM 5.3 Flash/Parasail route. Every case is the pinned corpus case, unmodified. All cases ran sequentially through the shared runner and replayed their receipts. Objective values are measured against upstream's own solver output (gurobipy for procurement, scipy for pricing), not a reimplementation.
